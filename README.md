# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. The application provides weather information in a clean and user-friendly interface.

## 🚀 Live Demo

👉 [View Weather App](https://nistha2145-cmd.github.io/WEATHER-APP/)

## ✨ Features

* 🌡️ Displays current temperature
* 💧 Shows humidity information
* 💨 Displays wind speed
* 🔍 Search weather by city
* ⚠️ Handles invalid city names
* 📱 Simple and responsive user interface
* 🌤️ Weather-related visual icons

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and dynamic weather data
* **Git & GitHub** – Version control and deployment
* **GitHub Pages** – Website hosting

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/nistha2145-cmd/WEATHER-APP.git
```

2. Open the project folder:

```bash
cd WEATHER-APP
```

3. Open `index.html` in your browser.

That's it! 🎉
